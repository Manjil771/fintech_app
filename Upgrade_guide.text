1. Open your terminal.
2. type "which flutter"
3. Copy the path before 'bin'

Example:

🕙 14:05:09 ❯ which flutter
/Users/nsubash38/development/flutter/bin//flutter

Copy : "/Users/nsubash38/development/flutter" (This is example, take path from your terminal output)

4. type "git checkout 3.27.0"

If that doesn't work try "git fetch"

5. type "flutter doctor" and wait for some moment

6. Now exit the terminal and open a new terminal inside vscode with project directory. 

7. cd ios 
8. pod install --repo-update

9. Open Xcode and try building the project. Let me know if you encounter any issue.
